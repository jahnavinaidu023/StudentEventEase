
# StudentEventEase 🎓

## 📌 About the Project
StudentEventEase is a web-based application designed to simplify student event management and make event-related activities easier to organize and manage.

## 🚀 Project Objectives
- Simplify student event management.
- Organize event-related information.
- Provide an easy-to-use interface.
- Improve communication regarding student events.

## 🛠️ Technologies Used
- Java
- HTML
- CSS
- JavaScript
- Apache Tomcat
- Maven

## 📂 Project Structure
- `src/` - Java source code
- `WebContent/` - Web application resources
- `pom.xml` - Maven configuration

## ⚙️ How to Run
1. Clone this repository.
2. Import the project into IntelliJ IDEA.
3. Configure Apache Tomcat.
4. Resolve Maven dependencies.
5. Run the application.
